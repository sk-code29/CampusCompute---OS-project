# CampusCompute
## Intelligent Job Scheduling and Resource Management

### Overview
CampusCompute is a C-based Operating Systems project that demonstrates
CPU scheduling, concurrent programming, inter-process communication,
deadlock avoidance, worker process management and resource limits.

### Technologies
- C programming
- Linux / Ubuntu
- GCC compiler
- POSIX threads
- POSIX shared memory
- POSIX semaphores
- Linux process management
- Make

### Features
1. FCFS CPU scheduling
2. Round Robin CPU scheduling
3. Non-preemptive Priority scheduling
4. Scheduling algorithm comparison
5. Producer-consumer synchronization using threads
6. Shared memory IPC
7. Banker's algorithm for safe and unsafe states
8. Worker process management and failure simulation
9. Resource limit demonstration
10. Command-line interface

### Project Structure
- main.c: Main menu and program entry point
- include/: Header files
- src/: Implementation files
- tests/: Individual module tests
- logs/: Generated system logs
- screenshots/: Project evidence screenshots
- Makefile: Build configuration

### Compilation
Run the following commands from the project directory:

    make clean
    make

### Execution
    ./campuscompute

### Testing
Individual test source files are available in the tests directory.

### Cleanup
    make clean
